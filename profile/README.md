# techne-tools is building code for live performance research

The intersections of live performance and technology are increasingly apparent while becoming steadily more seamless or even invisible. The techne-tools repository is about building tools that advance human-computer interaction and collaboration in a performance research context.

As technical artists in live theatre, we believe that - with ethical action and clear theoretical grounding - artists can be empowered by the rapid prototyping and conceptual exploration allowed by machine learning, creative code, and design-led performance practice. The tools being built here are means to that end.
